Detective

A mobile pass-and-play word bluffing game.

Players secretly receive words. One player is the impostor. The group gives clues, discusses, and votes.

How to Play

Civilians all receive the same word.

The impostor receives a different but related word.

If there are 5 or fewer players, the impostor gets a clue.

If there are 6 or more players, the impostor gets no clue.

When time ends, or Vote Early is pressed, everyone secretly votes by passing the phone.

Game Setup

Minimum players: 3. This version uses 1 impostor.
